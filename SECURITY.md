# Security policy

Insomemo reads window titles and, on macOS, page addresses through Accessibility, so privacy and security issues matter even though nothing leaves your computer except optional update checks.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. Do not open a public issue.

Include the affected version (`insomemo --version`), your operating system and desktop, and steps to reproduce. You can expect an acknowledgement within a week.

## Supported versions

Only the latest release receives fixes. Insomemo is pre-1.0, so a fix ships as a new release rather than a backport.
