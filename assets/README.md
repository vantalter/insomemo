# Insomemo artwork

- `TrayTemplate.png`: the 72-pixel keyboard mask used for the macOS tray, embedded in the executable and displayed at 20 points. macOS renders the template in white or dark to match the menu bar, including selected and high-contrast states. It is generated by [generate-tray-keyboard.m](../scripts/generate-tray-keyboard.m).
- `AppIcon.png`: the 1024-pixel app icon, the same keyboard mark with a fixed top-right dot on a purple tile. The packaged sizes in [AppIcon.appiconset](../macos/Insomemo/Assets.xcassets/AppIcon.appiconset) are rendered from the same geometry, and Xcode compiles them into the app's icons.
- `app-icon-original.png`, `tray-template-source.png`, `tray-template-side-arrows-source.png`: earlier versions of the app icon and tray mark, kept for reference. The build does not use them.

Both generators share [keyboard-artwork.h](../scripts/keyboard-artwork.h), so the keyboard silhouette stays consistent; the Linux tray icons in [tray_svg.rs](../src/tray_svg.rs) are drawn from the same geometry. The app icon clips the artwork to its inset tile, and the transparent key and badge cutouts reveal the gradient beneath.

To regenerate the tray mask from the repository root:

```sh
clang -fobjc-arc -framework AppKit scripts/generate-tray-keyboard.m -o /tmp/insomemo-tray-generator
/tmp/insomemo-tray-generator assets/TrayTemplate.png
```

To regenerate the 1024-pixel source and every packaged app-icon size:

```sh
clang -fobjc-arc -framework AppKit scripts/generate-app-icon.m -o /tmp/insomemo-app-icon-generator
/tmp/insomemo-app-icon-generator assets/AppIcon.png macos/Insomemo/Assets.xcassets/AppIcon.appiconset
```

The generator reads the icon set's [Contents.json](../macos/Insomemo/Assets.xcassets/AppIcon.appiconset/Contents.json) and renders each size from the vector geometry. Without the icon-set argument, it writes only the source PNG.

The Ko-fi logo in [KoFi.imageset](../macos/Insomemo/Assets.xcassets/KoFi.imageset) belongs to Ko-fi Labs and is used, under their brand guidelines, to link to the project's Ko-fi page. It is not covered by the project's MIT license.
