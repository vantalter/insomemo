# Insomemo artwork

- `app-icon-original.png`: the new neon artwork supplied by the user, unchanged.
- `AppIcon.png`: the static app icon, using the tray keyboard mark with its default top-right switch dot on a purple tile; resized into the app icon set, [AppIcon.appiconset](../macos/Insomemo/Assets.xcassets/AppIcon.appiconset), which Xcode compiles into the app's icons.
- `tray-template-source.png`: the original transparent monochrome extraction, with arrows above/below the keyboard, retained for comparison.
- `tray-template-side-arrows-source.png`: the previous version, with curved sync arrows on the left and right of the keyboard stack, retained for comparison.
- `TrayTemplate.png`: the current 72-pixel keyboard-only mask, embedded in the executable and displayed at 20 points. It is generated by [generate-tray-keyboard.m](../scripts/generate-tray-keyboard.m). macOS renders the template in white or dark according to the actual menu-bar appearance, including selection/high-contrast states.

The tray mask and app icon are drawn with Core Graphics. The app icon uses the same keyboard geometry as the tray and adds a static version of its switch dot. The original neon artwork remains available above.

To regenerate the current tray mask from the repository root:

```sh
clang -fobjc-arc -framework AppKit scripts/generate-tray-keyboard.m -o /tmp/insomemo-tray-generator
/tmp/insomemo-tray-generator assets/TrayTemplate.png
```

To regenerate the 1024-pixel source and every packaged app-icon size:

```sh
clang -fobjc-arc -framework AppKit scripts/generate-app-icon.m -o /tmp/insomemo-app-icon-generator
/tmp/insomemo-app-icon-generator assets/AppIcon.png macos/Insomemo/Assets.xcassets/AppIcon.appiconset
```

The generator reads [Contents.json](../macos/Insomemo/Assets.xcassets/AppIcon.appiconset/Contents.json) and renders each size directly from the vector geometry. Omitting the asset-set argument generates only the source PNG. Both generators share [keyboard-artwork.h](../scripts/keyboard-artwork.h), so the keyboard silhouette stays consistent. The app icon clips artwork to its inset tile; transparent key and badge cutouts reveal the gradient beneath.

The side-arrow revision was also prepared with the built-in imagegen tool; its edit and refinement prompts are recorded in [tray-side-arrows-prompts.txt](tray-side-arrows-prompts.txt).
